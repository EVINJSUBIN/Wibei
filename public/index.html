How the Audio Node Graph Works

Pure Web Audio API pipeline without external audio libraries. Simple, modular, and fast.

audio-pipeline.js JavaScript / Web Audio API 
// 1. Initialize AudioContext & AnalyserNode (256 FFT Bins)
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioCtx.createAnalyser();
analyser.fftSize = 256;

// 2. Underwater Lowpass Muffler Biquad Filter
const muffler = audioCtx.createBiquadFilter();
muffler.type = 'lowpass';
muffler.frequency.value = 650; // 650Hz cutoff creates the club bathroom vibe

// 3. Low-Shelf Bass Overdrive Node
const bassBoost = audioCtx.createBiquadFilter();
bassBoost.type = 'lowshelf';
bassBoost.frequency.value = 120;
bassBoost.gain.value = 10; // +10dB sub-bass drive

// 4. Chain Audio Nodes: Source → Muffler → Bass → Analyser → Speakers
source.connect(muffler).connect(bassBoost).connect(analyser).connect(audioCtx.destination);
