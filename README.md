# Wibei 🎵

A real-time 3D music visualizer made with Three.js and Web Audio API.

**Live Demo:** [https://wibei-production.up.railway.app/](https://wibei-production.up.railway.app/)

## Features
- 3D audio visualizer shapes (Pulse Ring, Wave, Matrix Grid)
- Live YouTube search & stream
- Mic input (🎤) and MP3 upload (📁)
- 3D mouse drag orbit and camera parallax
- Neon themes (Gold, Cyan, Magenta)

## How to run locally

1. Make sure you have Node.js and Python (`yt-dlp`) installed.
2. Clone and install:
```bash
git clone https://github.com/EVINJSUBIN/Wibei.git
cd Wibei
npm install
npm start
```
3. Open `http://localhost:3000` in your browser!
